# Whispryy — napisy na żywo

Whispryy zamienia rozmowę z kanału głosowego Discorda (albo dźwięk z przeglądarki czy innego programu)
na napisy na żywo, wprost na ekranie gry. Pokazuje, kto mówi, a mowa jest rozpoznawana lokalnie —
dźwięk nie opuszcza Twojego komputera.

**Strona:** https://hubert-kniola.github.io/whispryy-app/

## Pobierz

**[⬇ Pobierz Whispryy dla Windows](https://github.com/hubert-kniola/whispryy-app/releases/latest/download/Whispryy.zip)** — Windows 10/11 64-bit

1. Rozpakuj cały folder, np. na Pulpit albo do Dokumentów (nie do Program Files).
2. Uruchom `Whispryy.exe`. Jeśli Windows pokaże „System Windows ochronił komputer”:
   „Więcej informacji” → „Uruchom mimo to”.
3. Przy pierwszym uruchomieniu Whispryy pobierze model rozpoznawania mowy, a na kartach NVIDIA
   także biblioteki CUDA. Postęp widać w panelu.

Działa na kartach NVIDIA, AMD i Intel (bez karty graficznej — na procesorze).
Nowe wersje instalują się jednym kliknięciem w panelu, w zakładce **Aktualizacje**.

Wszystkie wersje: [Releases](https://github.com/hubert-kniola/whispryy-app/releases)
